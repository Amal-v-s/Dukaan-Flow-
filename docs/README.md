This folder contains the product, technical, security, design, API,
architecture, testing, and delivery documents for DukaanFlow.

## Documents

-   `01_PRD.md` --- Product requirements and acceptance criteria
-   `02_TRD.md` --- Technical requirements and stack
-   `03_DATABASE_SCHEMA.md` --- Firestore entities and integrity rules
-   `04_AUTH_SECURITY.md` --- Authentication and application security
-   `05_API_SPEC.md` --- API endpoints and request/response examples
-   `06_ENGINEERING_RULES.md` --- Engineering conventions
-   `07_AI_ASSISTANT.md` --- AI behavior and grounding contract
-   `09_TESTING_DEPLOYMENT.md` --- Test strategy and Google Cloud
    deployment
-   `APP_FLOW.md` --- Screen and user workflows
-   `ARCHITECTURE.md` --- Component architecture and data flow
-   `DELIVERY_ROADMAP.md` --- Four-phase product roadmap
-   `DESIGN.md` --- Merchant Flow Precision design system
-   `PRODUCTION_CODING_RULES.md` --- Production coding standards
-   `PRODUCTION_SECURITY.md` --- Production security requirements
-   `phase1_phases.md` --- Detailed Phase 1 implementation plan

## Important boundaries

Phase 1 uses sample/demo data and deterministic financial calculations.
No live bank integration, payment execution, loan origination, or real
late-fee collection is included. Gemini is deferred until Phase 3 and
must only explain server-calculated facts.
